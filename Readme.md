# Установка прошивки и AutoRus

> **Важно:** перед началом убедитесь, что автомобиль включён и мультимедийная система работает нормально. Во время обновления **не выключайте автомобиль, не извлекайте флешку и не нажимайте кнопки**, пока процесс не завершится.

## 1. Подготовка флешки

Отформатируйте USB-флешку в файловую систему **FAT32**.

После этого скачайте архив с прошивкой и **извлеките его содержимое в корень флешки**.

В результате на флешке должны находиться:

- **2 папки**;
- **1 архив**.

Структура должна выглядеть примерно так:

<img width="518" height="250" alt="Структура файлов на флешке" src="https://github.com/user-attachments/assets/67b0f4f9-bbbb-446f-9c91-e160f8729646" />

После этого можно переходить к автомобилю.

# 2. Проверка версии Flyme Auto

Для установки прошивки необходимо, чтобы на головном устройстве была установлена версия **Flyme Auto 2.3.0**.

Сначала откройте список приложений:

Прокрутите меню настроек **до самого низа** и откройте раздел с **иконкой человека**:

<img width="1448" height="1086" alt="Раздел настроек автомобиля" src="https://github.com/user-attachments/assets/7a9653a1-a17a-4d69-99ec-c46065a5c761" />

Здесь отображается установленная версия Flyme Auto.

# 3. Разблокировка инженерного меню

# 4. Установка прошивки

Теперь вставьте подготовленную ранее USB-флешку в USB-разъём автомобиля.

В инженерном меню нажмите **первую кнопку в левом верхнем углу**:

<img width="2576" height="1235" alt="Запуск прошивки через инженерное меню" src="https://github.com/user-attachments/assets/93e1ffa2-d268-4b91-be07-4a87f4c2efaa" />

Появится всплывающее окно.

В нём нажмите **правую кнопку**, чтобы подтвердить запуск обновления:

<img width="1448" height="1086" alt="Подтверждение установки прошивки" src="https://github.com/user-attachments/assets/0c36dd4b-8e96-4b53-b554-216496eae04c" />

Начнётся процесс подготовки обновления.

**Ничего не нажимайте и не извлекайте флешку. Просто дождитесь окончания процесса.**

<img width="1448" height="1086" alt="Процесс обновления" src="https://github.com/user-attachments/assets/cbee2827-daa9-4c80-a1d1-49a8084475b1" />

Через некоторое время экран головного устройства выключится.

Это нормально — после перезагрузки автоматически запустится основной процесс прошивки:

<img width="1367" height="1167" alt="Процесс установки прошивки" src="https://github.com/user-attachments/assets/30abc1b1-2d5f-4cb6-b651-0451e05c47d7" />

> **Не выключайте автомобиль и не прерывайте процесс прошивки.**

Дождитесь полной загрузки системы.

# 7. Перезагрузка головного устройства

На руле найдите **правую круглую кнопку**.

Нажмите и удерживайте её примерно **15 секунд**:

<img width="1254" height="1254" alt="Кнопка перезагрузки головного устройства" src="https://github.com/user-attachments/assets/9f9e6bc8-f1c6-4f79-b48e-ca936180a1d4" />

Продолжайте удерживать кнопку, пока экран головного устройства **полностью не погаснет**.

После этого кнопку можно отпустить.

> Во время длительного удержания кнопки автомобиль может начать говорить на китайском языке — **это нормально, продолжайте удерживать кнопку до выключения экрана**.

Головное устройство перезагрузится.

После загрузки системы установка и активация **AutoRus завершены**.
